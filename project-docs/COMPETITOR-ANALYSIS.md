## Top patterns adopted
1. Show value first (tool result), then ask (lead/email).
2. One repeated primary CTA; qualifying multi-step form with progress, channel choice, consent, honeypot.
3. Tool-page template: tool → how it works → examples → FAQ → sources → related tools.
4. Share-result links (URL parameters).
5. Trust: disclaimers, privacy, no fake testimonials, transparent pricing "from".
6. Dark mode, mobile-first, fast static pages, schema.org JSON-LD.
